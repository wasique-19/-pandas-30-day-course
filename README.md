# 📊 30-Day Pandas Mastery Course

A structured, day-by-day journey through the Pandas library — from absolute basics to advanced data analysis, culminating in a complete real-world end-to-end e-commerce analytics project.

This repository contains my daily practice exercises, coding challenges, and mini assignments as I work through a 30-day Pandas curriculum covering data cleaning, transformation, aggregation, merging, reshaping, time-series analysis, and a final capstone project.

## 🚀 How to Run

Clone the repo and run any day's scripts individually:

```bash
git clone https://github.com/wasique-19/pandas-30-day-course.git
cd pandas-30-day-course/Day01_Introduction_to_Pandas
python practice.py
```

Make sure Pandas and NumPy are installed:

```bash
pip install pandas numpy openpyxl
```
